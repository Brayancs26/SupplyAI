Configuración de GitHub

Leer el programa y los resultados NO necesita token (el repo es público). Solo necesitas el token para publicar el programa — configúralo una vez en este navegador.

Guardado ✓

Cómo crear el token: en GitHub, ve a Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Limita "Repository access" solo a este repositorio, y en "Permissions" dale a "Contents" el nivel "Read and write". El token queda guardado solo en este navegador — nunca se sube a ningún lado.
