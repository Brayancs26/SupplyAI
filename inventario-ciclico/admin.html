Configuración de GitHub

Ya no hace falta configurar nada por dispositivo — leer y guardar pasan por un Worker que guarda el token de forma segura. Esto funciona automático desde cualquier navegador o celular.

Guardado ✓

Estos 3 campos ya se detectan solos casi siempre — solo tócalos si algún día cambias el repositorio o la rama. El token vive únicamente en el Worker (nunca en el navegador ni en el código de la página) — si necesitas cambiarlo, se hace desde el panel de Cloudflare, no desde aquí.
